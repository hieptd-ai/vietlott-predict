Tự động Hóa Định kỳ

Định dạng NDJSON Chuẩn

Dữ liệu được lưu trữ dạng Newline Delimited JSON, tối ưu cho xử lý stream, append liên tục và tương thích Polars/Pandas.

Giao diện CLI Tiện lợi

Cung cấp sẵn các lệnh CLI vietlott-crawl và vietlott-missing để dễ dàng cào dữ liệu mới hoặc bù đắp các kỳ thiếu.

Hướng dẫn Sử dụng

Cài đặt & Giao diện Dòng lệnh (Go & Python)

Bộ cào Go tốc độ cao (khuyến nghị) hoặc gói Python PyPI cho phân tích dữ liệu

1. Bộ thu thập Go (Khuyến nghị cho thu thập dữ liệu)

Bộ cào Go chính thức (Go 1.27+) chạy nhanh hơn ~1.7× và tiêu tốn <2MB RAM. Do Vietlott chặn IP nước ngoài, hãy chạy từ IP tại Việt Nam:

bash (Go CLI) 
# Biên dịch binary bộ cào Go
$make build-crawler

# Kiểm tra trạng thái dữ liệu hiện có so với kỳ quay mới nhất
$./bin/vietlott-crawler status

# Đồng bộ toàn bộ sản phẩm & bù đắp các kỳ bị thiếu
$./bin/vietlott-crawler sync --all

# Cập nhật README và trang tài liệu HTML
$./bin/vietlott-crawler render-readme && ./bin/vietlott-crawler render-docs

2. Gói Python PyPI (Tích hợp Python & CLI Legacy)

Gói Python vietlott-data vẫn được duy trì trên PyPI để tích hợp vào quy trình phân tích dữ liệu (lưu ý: bộ cào CLI Python đang ở trạng thái legacy/deprecated, khuyến nghị dùng bộ cào Go ở trên):

bash (Python CLI) 
# Cài đặt gói Python qua uv hoặc pip
$uv add vietlott-data
$pip install vietlott-data

# Lệnh CLI Python (legacy)
$vietlott-crawl power_655
$vietlott-missing power_655

Câu hỏi Thường gặp về Dữ liệu Vietlott

Tải dữ liệu kết quả xổ số Vietlott đầy đủ ở đâu?

Toàn bộ lịch sử kết quả Vietlott (Power 6/55, Mega 6/45, Power 5/35, Keno, Max 3D, Max 3D Pro, Bingo18) được công khai miễn phí dạng NDJSON tại thư mục data/ của kho mã nguồn github.com/hieptd-ai/vietlott-predict và cập nhật hàng ngày.

Dữ liệu Vietlott có những sản phẩm nào?

Power 6/55, Mega 6/45, Power 5/35, Keno, Max 3D, Max 3D Pro và Bingo18. Mỗi bản ghi gồm ngày quay (date), mã kỳ quay (id), bộ số trúng (result) và thời điểm thu thập (process_time).

Dữ liệu được cập nhật bao lâu một lần và lấy từ đâu?

Dữ liệu được thu thập tự động từ trang chính thức vietlott.vn và cập nhật hàng ngày sau mỗi kỳ quay. Dự án có cơ chế phát hiện kỳ quay bị thiếu và tự động bổ sung (backfill).

Có thể dự đoán kết quả xổ số Vietlott bằng dữ liệu này không?

Không. Kết quả xổ số là ngẫu nhiên và không thể dự đoán. Dữ liệu chỉ phục vụ giáo dục, nghiên cứu và phân tích thống kê, không phải lời khuyên đánh bạc.

Cách dùng dữ liệu Vietlott trong Python?

Cài bằng `uv pip install vietlott-data` hoặc đọc trực tiếp bằng polars: `pl.read_ndjson('data/power655.jsonl')`. Lệnh `vietlott-crawl ` thu thập các kỳ quay mới nhất.

Tuyên bố Miễn trừ Trách nhiệm

Dự án này chỉ dành cho mục đích giáo dục, nghiên cứu dữ liệu và phân tích thống kê. Kết quả xổ số là hoàn toàn ngẫu nhiên và không thể dự đoán chính xác. Dự án không cung cấp bất kỳ lời khuyên đánh bạc hay bảo đảm trúng thưởng nào.
